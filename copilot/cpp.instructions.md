# C++ Standard

This repository is built using **C++17**. When writing or suggesting C++ code:

- Use C++17 language features and standard library facilities only.
- Do not suggest features introduced in C++20 or later (e.g., concepts, ranges, coroutines, modules, `std::span`, three-way comparison `<=>`).
- Prefer C++17 idioms such as `std::optional`, `std::variant`, `std::string_view`, structured bindings, and `if constexpr` where appropriate.
